CANOPY KIN: MOONROOT — WINDOWS FULL QUALITY v0.8.0

Keep CanopyKin.exe, CanopyKin_Data, MonoBleedingEdge, D3D12 and the DLL files
together in the same folder. Launch CanopyKin.exe.

Recommended target
- Windows 10/11 64-bit
- 1920 x 1080
- NVIDIA RTX 3060-class GPU
- High preset, approximately 60 FPS target

Controls
- WASD: move
- Mouse: orbit camera
- Shift: sprint
- Space: climb / vault
- E: interact or upgrade
- Left mouse: bite
- Q: tactical view
- Z / X / C: select all / workers / soldiers
- 1–7: gather / attack / follow / defend / patrol / retreat / return to nest
- F5 / F9: save / load
- Escape: pause and settings

The Windows edition retains full-resolution production textures and the highest
lighting, shadow, vegetation and view-distance profile. Medium and Low presets
remain available from the pause menu.
