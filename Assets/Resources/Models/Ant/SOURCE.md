# Canopy Kin production ant

- Creator: Moonroot Studio / original project work
- Source: `ArtSource/Ant/CanopyKinProductionAnt.blend`
- Generator: `Tools/build_production_ant.py`
- License: original project asset
- Geometry: one skinned mesh with anatomical exoskeleton islands
- Rig: root, thorax, abdomen, head, mandibles, antenna chains and four bones
  for each of six legs
- Authored clips: idle, walk, run, turn, attack, carry, climb, stagger and death
- Use: player, workers, soldiers and rival ant castes

The model is generated and exported in Blender, then imported as an FBX. It does
not use Unity sphere, capsule, cylinder or line renderers.
